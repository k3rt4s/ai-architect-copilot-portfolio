## What this stage does

Stage 3 opens an interactive Gemini chat session grounded in the stage 1 index and stage 2 gap analysis, with the Google Search tool attached so the advisor can pull in current standards, vendor documentation, and reference patterns. The user uses the session to rehearse for a real Architecture Review Board: defending design choices, exploring alternatives, and watching the advisor probe weaknesses the way an experienced reviewer would.

## What a working prompt covers

A production prompt for this stage typically covers:

- The advisor's tone (skeptical reviewer, not cheerleader).
- How to ask one focused question at a time rather than dumping a checklist.
- When to use Google Search versus reasoning from the indexed corpus.
- How to push back on weak justifications without being dismissive.
- How to recognize when the user has made the decision and the discussion is over.
- How to summarize the conversation into a "what to fix before the review" list on request.
